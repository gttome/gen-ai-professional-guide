How to use

  1. Select a prompt from the dropdown at the top.
  2. Switch views using the pills: Infographics, Video, Audio, Template.
  3. Favorite a prompt with the star to make it easier to return to later.
  4. Diagnostics helps you see which configured files are present or missing.
  5. Feedback lets you capture notes and export them as a text file.

This ZIP intentionally excludes the assets folder. To use real media, place your assets folder alongside index.html using the paths in data/prompts.json.

How to use

  1. Select a prompt using the dropdown next to the title.
    Each prompt can reference an infographic, video, audio file, and one or more templates.
  2. Switch views using the pill buttons: Infographics, Videos, Audio, Templates.
    • Infographics: choose Concise, Standard, or Detailed. Use Zoom controls and Reset. Use Open to view the infographic in a new tab sized to the viewport (no scrollbars for concise).
    • Videos: plays the configured video for the selected prompt (if present).
    • Audio: plays the configured audio for the selected prompt (if present).
    • Templates: edit the prompt template text and copy/download it. Use Load Template (base file) and Load Use Cases (companion “uc” file) when available.
  3. Favorites: click the star (☆/★) to save the current prompt in Favorites (stored locally in your browser).
  4. Theme: use the Theme button to toggle Light/Dark mode.
  5. Feedback: use the floating Feedback / Contact button to email feedback. The app name is included automatically.

Tip: if media files don’t load, confirm you are running start-server.bat and that the files referenced in data/prompts.json exist alongside the app.

Always Include Prompt

PROMPT TEMPLATE

The "Always Include" prompt is a persistent configuration technique that forces the AI to systematically attach specific content—such as disclaimers, signatures, or instructional wrappers—to the beginning or end of every subsequent response. This ensures strict adherence to compliance, branding, or safety protocols throughout a session without requiring the user to repeat the instruction.

Syntax:
Configure the system to [prepend/append] the text '[Text]' to all responses generated after this prompt is executed. This setup should align with the described scenario, ensuring consistent inclusion of the user-defined text in each interaction for the stated purpose. Include an example of how the text would appear in the response.

Usage Instructions:
Action [Prepend/Append]: Choose "Prepend" to place text before the main response (ideal for safety warnings or context setting) or "Append" to place it after (ideal for signatures, surveys, or disclaimers).
Text: The exact string of text, including formatting or links, that must appear in every output.
Persistence: This instruction creates a session rule; the AI will apply this formatting to all future answers until told otherwise.

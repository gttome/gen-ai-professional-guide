Include Markdown Prompt

PROMPT TEMPLATE

The "Include Markdown" prompt is a formatting-centric technique that compels the AI to structure its output using specific Markdown syntax. By explicitly requesting elements like tables, headers, bold text, or lists, the user ensures the response is visually organized, readable, and ready for professional presentation or documentation.

Syntax:
You are an expert in [Role]. Please create a [Output Type] regarding [Topic].
You must utilize the following Markdown formatting elements in your response:
[List of Elements: e.g., Tables, Headers, Bold key terms, Bullet points, Blockquotes].
Ensure the final output is visually structured for [Purpose] and strictly adheres to the requested formatting.

Usage Instructions:
Role: Define the persona (e.g., "Technical Writer," "Data Analyst").
Formatting Constraints: Explicitly list the Markdown elements required. For example, request a "table" for data comparison or "bold" for emphasis on specific terms.
Purpose: Clarify how the output will be used (e.g., "for a vacation response," "for a project update") to guide the tone and structure.

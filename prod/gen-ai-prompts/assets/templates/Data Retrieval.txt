Data Retrieval Prompt

PROMPT TEMPLATE

The "Data Retrieval" prompt is a structured extraction technique designed to mine specific information from large blocks of unstructured text. By defining precise data points and requesting a tabular output, this method transforms qualitative content (like reviews, transcripts, or reports) into quantitative, analyzable datasets.

Syntax:
Text: "[Paste the text containing the information you need to retrieve]"
Retrieve the following data points separated by commas from the text above:
[data1]
[data2]
[data_nnn]
Create a markdown table with the retrieved data:
Ensure the table is formatted in markdown for readability and professionalism.

Usage Instructions:
Input Text: Paste the raw content (emails, articles, logs, etc.) into the "Text" field.
Data Points: List the specific entities or themes you need to extract (e.g., "dates," "error codes," "sentiment").
Output: The prompt explicitly forces a table format to ensure the results are ready for immediate analysis or export.

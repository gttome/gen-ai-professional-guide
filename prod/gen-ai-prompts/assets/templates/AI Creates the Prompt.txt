AI Creates the Prompt

TEMPLATE

The "AI Creates the Prompt" technique is a meta-prompting strategy where the user empowers the AI system to generate and execute its own optimized prompt based on a raw request. This method overcomes user uncertainty about how to phrase complex inquiries by leveraging the AI's ability to structure instructions for maximum relevance and efficiency.

Syntax:
Please create a prompt that will complete a request and format the output in a professional manner. REQUEST [Request]. Please create this prompt then use it to complete the request. Do not use code blocks.

Usage Instructions:
    Request: Input your raw, unstructured, or complex goal here. The AI will analyze this input to determine the necessary context and constraints.
    Mechanism: The AI performs two distinct actions: first, it drafts a "professionally formatted" prompt tailored to the specific domain; second, it immediately uses that prompt to generate the final response.
    Value: This ensures the user receives a response derived from a highly optimized instruction set, even if their initial input was vague or poorly structured.

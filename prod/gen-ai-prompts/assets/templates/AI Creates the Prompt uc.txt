AI Creates the Prompt

USE CASES

The following examples demonstrate the "AI Creates the Prompt" methodology applied to high-complexity domains where the user knows the desired outcome but relies on the AI to formulate the technical constraints required to achieve it.

GENOMIC RESEARCH

    Scenario:
    A Bioinformatics Researcher has a raw dataset of gene sequences and needs to identify potential CRISPR off-target effects but is unsure how to parameterize the search query for the AI.

    Prompt:
    Please create a prompt that will complete a request and format the output in a professional manner. REQUEST [Analyze the provided FASTA dataset of Cas9 target sequences to predict potential off-target cleavage sites in the human genome; I need the analysis to account for 3-4 base pair mismatches and prioritize exonic regions over intronic ones]. Please create this prompt then use it to complete the request. Do not use code blocks.

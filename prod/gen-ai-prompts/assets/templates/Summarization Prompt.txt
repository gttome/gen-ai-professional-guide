Summarization Prompt

PROMPT TEMPLATE

The "Summarization Prompt" (specifically the "Precision Text Summarization" technique) is an iterative density method. Instead of simply shortening text, this prompt generates five distinct variations of a summary, all keeping to the same word count. With each iteration, the AI is tasked with increasing the "information density"—incorporating new key points while retaining essential information from the previous version—resulting in a final "Ultra-Dense Distillation" that maximizes content within a fixed constraint.

Syntax:
Precision Text Summarization
Welcome! Let's transform content into a series of increasingly potent summaries.
Choose your summary length: How many words would you like each summary to be? (Recommended: 50-100)
[Wait for user input]
Provide your content: [Paste text or upload document]
Your task: Create 5 summaries of the content, each containing exactly [user's chosen word count].
Label each summary as follows:

1. Broad Overview
2. Focused Recap
3. Condensed Synopsis
4. Concentrated Extract
5. Ultra-Dense Distillation

Guidelines:

* Keep the word count consistent across all summaries.
* Each new summary should incorporate new key points from the content.
* Retain all important info from the previous summary.
* Increase information density with each iteration.
* Ensure each summary can stand alone.
* Begin with a verbose overview and progressively refine to create an ultra-dense final summary.

Usage Instructions:
Word Count: The user must define a strict constraint (e.g., "100 words"). This forces the AI to trade stylistic fluff for hard data as the density increases.
Iterative Process: The output will provide five versions. The first is a general introduction; the fifth is a highly compressed, fact-heavy extraction.
Density: The core mechanic is "increasing information density," which compels the AI to rewrite sentences to hold more facts per word.
